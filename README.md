# Portafolio — Noe Herrera

Portafolio personal de Noe Herrera, estudiante de Ingeniería en Desarrollo y Gestión de Software con enfoque Full Stack. Presenta su perfil profesional, formación académica, habilidades técnicas y proyectos desarrollados.

## Tecnologías

- React + TypeScript
- Tailwind CSS
- Vite

## Desarrollo

```bash
bun install
bun dev
```

El contenido del portafolio (textos, enlaces, proyectos y CV) se edita en `src/data/portfolio.ts`.
